# Experimental Cloudflare analytics

The Worker, D1 migration, first-party adapter, dashboard, and original design documents are retained for V2 research only. They are not copied into `dist`, referenced by the production runtime, exposed in navigation, or deployed by the V1 workflows.

Code lives in `experimental/cloudflare-analytics/`. The documents in this directory describe the superseded prototype and must not be followed for V1 production setup.
