# AllTools

AllTools provides free online tools for everyone. It is a fast, mobile-first collection of browser-based utilities published as a fully static application on GitHub Pages using HTML, CSS and Vanilla JavaScript.

Production: [https://tutkutuzlu.github.io/alltools/](https://tutkutuzlu.github.io/alltools/)

## V1 architecture

- Folder-discovered tool plugins
- Reusable Text Tools and Developer Tools families
- Minimal Component Registry
- Light, dark and system themes
- Static HTML build with automatic category and tool discovery
- Client-side search index
- Static SEO metadata, structured data, sitemap and robots.txt
- GitHub Actions validation and GitHub Pages deployment

The current catalog contains browser-local Text Tools and Developer Tools. New plugins are discovered from metadata and rendered into category pages, search and the sitemap automatically.

## Requirements

- Node.js 20 or newer
- npm

The project has no runtime or build dependencies outside Node.js.

## Commands

```bash
npm ci
npm run check
npm run dev
```

The local preview is served at:

```text
http://localhost:4173/alltools/
```

Other commands:

```bash
npm run validate
npm run test
npm run build
npm run tool:new -- --name "Tool Name" --slug tool-name --category text
```

## Adding a tool

Each tool is an independent plugin under `src/plugins/tools/` with:

```text
tool.json
content.md
index.js
```

The build discovers published plugins automatically. The home page, category pages, search index and sitemap must not be edited manually.

## Generated output

`dist/` is generated by `npm run build` and is not committed. GitHub Actions builds and uploads it as a Pages artifact.
