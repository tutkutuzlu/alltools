# Security & Generators family

This family centralizes browser-native Web Crypto hashing, HMAC and secure randomness plus password, passphrase, PIN, checksum and UUID v7 helpers. The universal runtime never persists inputs or generated values and sends only allowlisted interaction metadata through the shared telemetry API.

The tools offer useful primitives and local analysis, not complete security guarantees. SHA-1 and non-cryptographic checksums are clearly labeled for their limited roles.
