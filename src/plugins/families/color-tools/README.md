# Color Tools family

Color Tools use one declarative catalog, a shared safe parser/conversion engine and one browser runtime. Thin tool entries export the common lifecycle. Values remain local and telemetry receives only the tool id, category and interaction type.

The engine supports HEX/alpha, RGB(A), HSL(A), HSV(A), CMYK, deterministic palettes, gradients, compositing and WCAG 2 contrast calculations.
