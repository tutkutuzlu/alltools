## Frequently asked questions

### How is a numeric unit detected?

Values with ten or fewer digits are treated as seconds in auto mode; longer values use milliseconds.

### Can I use this tool on mobile?

Yes. The editor, controls and results adapt to narrow screens and remain available from a keyboard.
