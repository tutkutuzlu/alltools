## Pick visually or enter an exact value

The native picker is useful for visual exploration, while the manual field is better when a designer or stylesheet already supplies an exact value. Moving the native control writes its six-digit HEX selection into the manual field. Editing the manual field updates the preview and result, but it does not move the native control in the opposite direction.

Manual input accepts HEX, RGB, HSL, HSV and CMYK forms supported by the shared parser. A value such as `#3366CC80` produces a preview plus normalized HEX, RGBA, HSLA, HSV and CMYK lines. Alpha is retained in HEX, RGB, HSL and HSV output; CMYK output itself has no alpha component.

Choose this tool when comparing how one color is represented across several models or when collecting values for a design handoff. The browser-native picker normally selects opaque sRGB-style colors and its visual interface differs by browser and operating system.

The CMYK line is a mathematical estimate without a print profile, and rounded formats may not reproduce every original decimal.
