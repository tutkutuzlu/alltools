## Text Sorter for focused text work

Sort lines alphabetically, numerically or by length. All processing happens immediately on this page, so the result is available without an account or upload.

## How to use Text Sorter

1. Type or paste the source text into the input editor.
2. Choose any available mode or comparison options.
3. Review the result, then copy or download it when available.

## Practical example

Order a mixed list of issue numbers numerically instead of using lexical order where 10 appears before 2.

## Privacy

Your text stays in your browser. The input and result are processed locally and are never included in analytics events.

## Frequently asked questions

### Does sorting remove duplicate lines?

No. Every input line remains; use Remove Duplicate Lines first when uniqueness is required.

### Does it work on mobile devices?

Yes. The controls, editor and results adapt to narrow screens and remain accessible from a keyboard.
