## Match the tool to the development task

Choose a **formatter** to make valid JSON, XML, HTML, CSS or SQL easier to read, and a **minifier** to remove nonessential formatting. **Validators** answer whether a value follows a syntax or identifier rule; **parsers** expose the parts of URLs, query strings, tokens or schedules. **Encoders and converters** change representation, while **generators and references** create identifiers or look up stable facts such as status and MIME types.

Every tool in this category runs locally. A formatter does not replace validation, and a parser does not prove that decoded data is trusted or safe to execute.
