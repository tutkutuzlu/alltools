## Choose a text workflow

Use **counters** to measure words, characters, lines, sentences or paragraphs without changing the source. Choose **cleaners** when spacing, blank rows or duplicate lines are the problem. **Transformers** change case, ordering or text direction, while **codecs** such as URL, Base64 and HTML tools translate between readable text and an encoded representation. Generators create new text rather than modifying an input.

These tools process text in the browser. Select the narrowest tool for the task so its options and output remain easy to verify.
